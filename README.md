# Satin network
Satin network is a research and lab organization researching cyber security and operational security to create full on top-tier applications. Here's a list of what we provide:
- High quality documentation
- High quality commenting and code
- High quality applications
- Clean UI for all applications
All our applications are open source. If you use any of our applications please star it on github!
