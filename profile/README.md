# Satin Network

Satin Network is a research and lab organization focused on cybersecurity and operational security. We build full-fledged, top-tier applications.

## What We Provide

- High-quality documentation
- High-quality commenting and code
- High-quality applications
- Clean UI for all applications

All our applications are open source. If you use any of our applications, please star it on GitHub!

## Applications

We create applications with very high quality. We make sure each one is the best we can make it. We create free, top-tier websites, applications, and tools because we want to build trust as a useful organization. We will remain like that for as long as we can.

You can send custom requests to our [email](mailto:satinnetwork@proton.me) for a new open source repo. Otherwise, if it's just for you, that's a private application which costs money.

### Issues

If you have any issues with any of the applications, create an issue or contact our [email](mailto:satinnetwork@proton.me) and we'll resolve it ASAP.

### Private Applications

Private applications are websites, applications, and tools that are special and cost money. We only accept crypto. Here are our payment options:

- Bitcoin
- Litecoin
- Solana

Private applications are crafted for absolutely insane quality. They are all as best as we can make them. The price depends on how difficult it was to make, how useful it is, and how much demand there is for it in the market.

Private applications can also be requested to be made for one specific user. The difference between a private and public request for an application to be made is that the private application is always accepted if you have money; the public one, not so much. The public application is also not crafted to our very best abilities.
